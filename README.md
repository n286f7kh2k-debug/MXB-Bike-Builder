# MXB Bike Builder

Official update distribution repository for MXB Bike Builder.

The app checks `latest.json`, verifies the published ZIP with SHA-256, installs the update over the existing copy, preserves user settings/custom bike packs, and restarts automatically.

## Update channel

The built-in updater uses:

`https://raw.githubusercontent.com/n286f7kh2k-debug/MXB-Bike-Builder/main/latest.json`

Release ZIP files are stored under `releases/`.
